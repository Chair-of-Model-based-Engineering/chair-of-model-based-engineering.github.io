# Project group / Project work “Software Engineering”

**Summer semester / Winter semester**

**Event number:** 43MBE1020V

The project groups/project works we offer deal with the practical application of diverse topics from the fields of software engineering and database systems.

Project groups/project works are preferably worked on in groups of at least 3 students. Project groups/project are usually worked on in the span of two semesters.

If you are interested, please contact us in a timely manner and enroll in the event in Unisono.

## Finished project groups

- Model-Checking of Database Manipulation Processes (2024)
- FAIR data management for physical experiments (2022)
