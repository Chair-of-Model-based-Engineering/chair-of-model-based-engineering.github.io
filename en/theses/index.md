# Theses

## Open theses

We offer theses in the following topics:

- Model-based Software Development and Quality Assurance
- Configurable Software
- Design of Database Applications
- Quantum Software Engineering

Please contact us in a timely manner if you are interested.

## Templates

- [LaTeX-Template for theses at the Chair of Model-based Engineering](https://nc.informatik.uni-siegen.de/s/wdBQYiXsyXGi6re/download/Abschlussarbeiten-MBE-Vorlage.zip)
- [PowerPoint-Template for presentations at the Chair of Model-based Engineering](https://nc.informatik.uni-siegen.de/s/A2TWMAkAcDjzw9S/download/MBE-Folienvorlage.potx)

To edit and typeset LaTeX documents, we recommend using [MiKTeX](https://miktex.org/) (which contains the editor TeXworks) or [Overleaf](https://www.overleaf.com).
